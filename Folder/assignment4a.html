During this activity, I learned about Internet reference models, Internet protocols, and the Domain Name System (DNS). I studied the four layers of the Internet Protocol Suite: Link, Internet, Transport, and Application. Each layer performs a specific function that helps devices communicate over the Internet. I also learned how protocols such as HTTP, TCP, IP, and DNS work together to transfer information from one device to another. One of the most interesting topics was DNS. Before this lesson, I did not realize that websites use numerical IP addresses behind the scenes. DNS translates easy-to-remember domain names such as www.google.com into IP addresses that computers can understand. The diagrams and examples helped me understand how data travels across networks and how different protocols interact to provide Internet services. This activity improved my understanding of how the Internet functions and how users can access websites quickly and efficiently.

I reviewed my computer's network settings and learned how to verify Internet connectivity using different networking tools. I examined IP address information and learned the difference between an IP address and a MAC address. I also learned how DHCP automatically assigns IP addresses to devices on a network. Using networking tools such as ping, traceroute, and nslookup, I tested network communication and DNS name resolution. Ping helped me verify connectivity between devices, while traceroute showed the path that packets take across the Internet. Nslookup demonstrated how domain names are translated into IP addresses. I also researched file sharing, Internet service providers, and home network components. I learned that a modem, router, wireless access point, and firewall are important parts of a home network. My biggest "aha" moment was realizing how many technologies work together behind the scenes to make Internet communication possible. This knowledge will help me troubleshoot network problems and better understand how computer networks operate in daily life.
